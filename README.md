# Hypocrates dental — demo (prebuilt)

Ready-to-run build of the dental dashboard in demo mode (sample data, no backend).
Source lives in the Hypocrates-Demos repo; this repo only holds the built app.

## Hostinger settings
- Framework preset: **Express** (auto-detected; the app is already built)
- Node.js version: **22**
- Build command: leave empty
- Entry file: **server.js**

Run locally: `npm install` then `npm start` (port 3000 or $PORT).

Login: admin@hypocrates.local / Admin123!
